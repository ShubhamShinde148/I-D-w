# Maharashtra Govt. Employee ID Card Generator (महाराष्ट्र शासन ओळखपत्र निर्मिती पोर्टल)

A web-based ID card generator for Maharashtra Government and Zilla Parishad Pune employees.

## Features
- **Front & Back Side Generation:** Real-time preview and generation of both sides of the official ID card.
- **Bilingual Support:** Form inputs and card layout formatted for Marathi (Devanagari) and English.
- **Custom Assets & Overlays:** Includes official emblems, district seals, stamps, and layout templates.
- **Photo & Signature Upload:** Easily upload and position employee photos and authorized signatures.
- **Instant Preview & Print:** Print-ready rendering with high-resolution export.

## Tech Stack
- HTML5, CSS3, JavaScript (Vanilla)
- Google Fonts (Noto Sans Devanagari, Inter, Poppins)

## Getting Started

1. Clone or download the repository:
   ```bash
   git clone https://github.com/ShubhamShinde148/I-D-.git
   ```
2. Open `index.html` in any modern web browser, or serve it locally:
   ```bash
   python -m http.server 3000
   ```
3. Visit `http://localhost:3000` to use the application.
